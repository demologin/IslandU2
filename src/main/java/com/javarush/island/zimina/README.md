# Симуляция острова — Зимина

## Описание

Симуляция экосистемы острова с животными и растениями. Реализована обязательная
часть задания (иерархия ООП, поведение животных, многопоточность, статистика
по тактам) и часть опциональной (вынесенные в конфиг параметры, JavaFX-визуализация,
15 видов животных).

## Архитектура

- `config` — загрузка параметров симуляции из YAML (SnakeYAML)
- `map` — остров и его клетки (100×20), потокобезопасный доступ через `Lock`
- `model` — базовые классы (`Organism`, `Animal`, `Plant`)
- `model.animals` — иерархия видов: `Herbivore` / `Predator` / `Omnivore`,
  15 конкретных видов, интерфейс `Carnivorous`
- `simulation` — заселение острова, фабрика животных
- `engine` — логика одного такта симуляции (5 последовательных фаз: движение,
  голод, еда, размножение, рост), статистика
- `ui` — JavaFX-визуализация (живая столбчатая диаграмма популяции по дням)
- `util` — вспомогательные утилиты (генерация вероятностей)

## Многопоточность

Такты запускаются по расписанию через `ScheduledExecutorService`. Внутри
каждого такта пять фаз выполняются последовательно, а обработка клеток
внутри каждой фазы — параллельно (по строкам острова) через `ExecutorService`.
Синхронизация — через `Lock` на каждой клетке.

## Запуск

Консольная версия:

mvn exec:java -Dexec.mainClass="com.javarush.island.zimina.Main"


Версия с графикой (JavaFX):

mvn javafx:run


## Конфигурация

Все параметры видов (вес, скорость, потребность в пище, лимит на клетку,
стартовое количество, вероятности поедания добычи) — в `resources/config.yaml`,
ничего не захардкожено в коде.
